How GG behaves while you work in Gmail.

    Presets

    Keyboard Shortcuts

    These run on top of Gmail's own shortcuts. Turn on Keyboard shortcuts in Gmail settings → General. GG turns it on for you the first time you open each account. Changes take effect instantly.
